# Portfólio Pessoal & Memorial Acadêmico - Eduardo Aires

Este repositório contém o código-fonte da aplicação web do Portfólio Pessoal e Memorial Acadêmico de Eduardo Gabriel Santos Aires, desenvolvido para a disciplina de Programação Web Front-End da Universidade Tiradentes (UNIT).

## Funcionalidades e Seções

A aplicação foi estruturada em uma única página com navegação por âncoras internas:

1. Sobre Mim (#sobre): Apresentação profissional e links sociais.
2. Portfólio (#portfolio): Cards dos projetos PerfilExato e LDL Fitness.
3. Habilidades / Skills (#skills): Barras de progresso técnicas.
4. Contato (#contato): Canais diretos, mapa macro e formulário validado via JS.

## Tecnologias Utilizadas

- HTML5 Semântico
- CSS3 Responsivo (Flexbox, Grid e Media Queries)
- JavaScript Vanilla (DOM e Regex)

## ## Como Executar o Projeto

1. **Clonar o repositório:**

git clone [https://github.com/dudu-airess6/portifolio]


2. **Navegar até a pasta do projeto:**

cd portfolio

3. **Abrir a aplicação:**
  * Basta dar um duplo clique no arquivo `index.html` ou abri-lo diretamente em qualquer navegador web (Google Chrome, Firefox, Edge, etc.).
